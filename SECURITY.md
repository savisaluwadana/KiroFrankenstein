# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub security advisories: open the repository's **Security** tab and choose **Report a vulnerability** (<https://github.com/savisaluwadana/KiroFrankenstein/security/advisories/new>). Do not open a public issue for a security problem.

Include what you found, how to reproduce it, and which commit or deployment you tested. This is a hackathon project maintained by one person, so there is no response-time guarantee.

## Scope

The security model, its credentials (read IDs, write tokens, the optional LLM access code) and its known limits are described in [docs/security-model.md](docs/security-model.md). No public deployment exists at the time of writing.

Never include real API keys or database credentials in a report.
